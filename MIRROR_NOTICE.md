# Read-only mirror

This repository is a **read-only mirror** of the `php/` subdirectory of
[lordmacu/nexo-plugin-sdks](https://github.com/lordmacu/nexo-plugin-sdks).
It exists only so Packagist (which needs `composer.json` at a repo root) can
track the `nexo/plugin-sdk` package. **Do not open PRs here** — file issues and
changes against [nexo-plugin-sdks](https://github.com/lordmacu/nexo-plugin-sdks).
